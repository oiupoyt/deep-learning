# deep-learning

LearnHarness's learning loop, ported natively into the
[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) as a
plugin: measure, plan, teach, practice — plus the persistent knowledge
graph, background research/demo/figure agents, and a practice mode.

Ported from [amosblomqvist/learnharness](https://github.com/amosblomqvist/learnharness)
(AGPL-3.0). This repository keeps that license and attributes the original
in [NOTICE](NOTICE). See the original for the teaching methodology's full
write-up; the prompts here carry it.

*Status: under construction — install/usage docs land with the first
working release. The README will cover: install (profile link or npm),
usage (sessions, graph, practice, settings), and how LearnHarness model
roles (teacher/prober/practice conversation, researcher, demoBuilder,
extractor, auditor, visualMaker, pdfReader) map to harness settings
(per-session model picker + background role pins).*
